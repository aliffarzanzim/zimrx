## Where to Find Open-Source SVGs (for future)

* **[FreeSVG.org](https://freesvg.org)**: All Public Domain (CC0). Search keywords: `stethoscope`, `heart`, `tooth`, `baby`, `brain`. Download direct SVG.
* **[Servier Medical Art](https://smart.servier.com)**: CC BY 4.0. Browse specialty, pick simple line art / silhouette SVGs.
* **[Wikimedia Commons](https://commons.wikimedia.org)**: Search `<keyword> filemime:image/svg+xml`. Filter by Public Domain or CC-BY.
* **Google Images**: Search `<keyword> vector svg` > Tools > Usage Rights > **Creative Commons licenses (Always Choose CC0 (Public Domain))**.
* **Must Verify The license**: Before using any image, verify its license to ensure it is free for our future vision and scalability.
